## Agent skills

### Issue tracker

Issues and specs are tracked as local Markdown under `.scratch/<feature-slug>/`. Before creating, fetching, or updating tickets or specs, read `docs/agents/issue-tracker.md`.

### Triage labels

Triage uses the default canonical labels. Before triaging an issue, read `docs/agents/triage-labels.md`.

### Domain docs

Domain documentation uses a single-context layout: root `GLOSSARY.md` and `docs/adr/`. Before exploring domain concepts or proposing architectural changes, read `docs/agents/domain.md`.
