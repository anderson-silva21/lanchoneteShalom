# Lanchonete Shalom

## Language

**Perfil de acesso (role)**:
Conjunto de permissões atribuído a um usuário da Shalom: Admin, Gerente, Caixa, Financeiro ou Livraria. Um usuário pode ter vários perfis simultaneamente.

**Permissões efetivas**:
União das permissões de todos os perfis de acesso atribuídos ao usuário, sem precisar escolher um perfil ativo.

**Administrador ativo**:
Usuário ativo com o perfil Admin. Sempre deve existir pelo menos um para administrar os acessos do sistema.
